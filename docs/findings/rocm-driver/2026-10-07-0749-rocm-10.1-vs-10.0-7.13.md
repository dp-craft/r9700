# ROCm 10.1 vs 10.0 vs 7.13 — what changed on this machine (R9700 / gfx1201)

- **Date:** 2026-10-07 07:49 · **Track:** environment audit (on-machine measurement)
- **GPU/Host:** AMD Radeon AI PRO R9700 (gfx1201), 32 GB · Ubuntu 24.04 · kernel 7.0.0-38-generic
- **Provenance note (iron rule 1):** every row below is `MEASURED` on this machine today unless tagged
  otherwise. The `rocmradeon` apt line / `amdrocm-*` packages / ROCm 10.x are **not documented anywhere
  public** reachable from this environment (research pass 2026-10-06: rocm.docs.amd.com, github.com/ROCm,
  Phoronix, mesa3d.org — none mention them; newest *public* ROCm release is 7.14.0, CLAIMED
  [github.com/ROCm/ROCm/releases](https://github.com/ROCm/ROCm/releases)). Anything about what AMD changed
  between these versions is therefore `UNVERIFIED` — the table records only what the installed trees show.

**Bottom line:** the only compiler-level difference visible on-machine is the **clang 23 → 24 major bump in
10.1**. 10.1 was installed as a *partial* component set (30 pkgs vs 53 for 10.0) but contains everything the
llama.cpp ROCm build needs: `hipcc`, `hipconfig`, `amdclang`, `amdlld`, `libamd_comgr.so.3`,
`libamdhip64.so.7`, `libhipblaslt.so.1` (all MEASURED present under `/opt/rocm/core-10.1/`).

## How 10.1 became active

- Package manager: apt line `https://repo.radeon.com/rocmradeon/apt/26.14 noble main` (+ `graphics/26.12`
  for Mesa) — MEASURED in `/etc/apt/sources.list.d/rocm.list`. Candidate for `amdrocm-core10.1-gfx1201` is
  `10.1.0-3` = installed → **up to date**, nothing newer offered on this line (MEASURED `apt-cache policy`).
- Active stack resolution: `hipcc` → `/opt/rocm/core-10.1/lib/llvm/bin`, `hipconfig -R` →
  `/opt/rocm/core-10.1` (MEASURED). New builds therefore link against 10.1 automatically.
- Layout: all three stacks live side by side as `/opt/rocm/core-{7.13,10.0,10.1}/`; `/opt/rocm/.info/version`
  is **missing in every tree** (MEASURED; already missing under 7.13 per the 2026-09-10 pre-upgrade state
  capture) — scripts that read it silently report `?`.
- Component naming changed between lines: 10.0 shipped `amdrocm-core-sdk10.0-gfx1201` +
  `amdrocm-core-dev10.0-gfx1201`; 10.1 ships a single `amdrocm-core10.1-gfx1201` (MEASURED via `dpkg -l`).
