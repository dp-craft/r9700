## Lessons from this session (avoid repeating)

- Never run `pkill -f`/`pgrep -f` with a plain pattern — it matched its own shell and killed it. Split the pattern.
- A load-time VRAM peak is not bounded by `--gpu-memory-utilization`; the desktop shares the card → keep the watchdog on.
- vLLM ≥ ~0.29 streams thinking as `delta.reasoning`; with `max_tokens 256` all of it can be thinking.
- After a session crash, the container keeps running and holds VRAM — always check `docker ps` + FREE_VRAM first.
- Sly's README quickstart pins an old tag (1.1.0); `serve.sh`/compose default to other images. The profiles follow the
  README docker recipe on 1.6.0 with documented deviations (util 0.90, `--shm-size` instead of `--ipc=host`, port bound
  to 127.0.0.1, `no-new-privileges`, numeric GIDs).
