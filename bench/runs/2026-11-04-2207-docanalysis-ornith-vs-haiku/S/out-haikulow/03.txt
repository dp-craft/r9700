TOPIC: Diagnoses a random HSA memory fault in vLLM (Sly radiance MXFP4 + DFlash) on R9700 and tests whether HIP_FORCE_DEV_KERNARG=0 removes it.
VERDICT: Setting HIP_FORCE_DEV_KERNARG=0 (kernel args in host memory) removed the memory faults in 3 of 3 boots, and it is now the default in the vLLM profiles. The root cause is inferred from a corrupted pointer, and the fix is not yet confirmed on kernel 7.0.0-38.
