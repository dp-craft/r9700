TOPIC: Root cause and fix for random HSA memory faults in vLLM Sly radiance MXFP4 + DFlash on the R9700 during Claude Code turns.
VERDICT: The random memory faults came from a corrupted kernel-argument pointer, and HIP_FORCE_DEV_KERNARG=0 removed them in 3 clean boots, which the report calls strong but not final (INFERRED). With the fix, decode ran at 111–150 tok/s median and prefill at 2.4–3.0k tok/s median (MEASURED).
CONFIG: vLLM via ghcr.io/slybase/vllm-sly-radiance:1.6.0-rocm10.1 (vLLM 0.31.0, AITER 0.1.23); amd/Qwen3.8-27B-Quark-AWQ-MXFP4 with DFlash2 drafter syvai/Qwen3.8-27B-DFlash2-W4A16, k = 7, greedy; max-model-len 180000, max-num-seqs 1, gpu-memory-utilization 0.90, KV fp8, R4D_HYBRID attention, prefix caching on; env HIP_FORCE_DEV_KERNARG=0; kernel 7.0.0-34-generic for the fix runs.
