D3 src/screens/resolve-confirm.ts: the g walk (in resolveConfirmScreen). `g` on main → phase
   'walk', index 0, walked reset. The walk iterates the INPUT lists: the entry at index is a
   goal when index < input.goals.goals.length (input.goals.goals[index]), else
   input.goals.nonGoals[index - input.goals.goals.length]. The prompt is
   `<entry.id>: <entry.text> (Enter keep, r replace, d drop)`. Enter (empty line) → keep the
   entry (walked grows), index+1. `r` → phase 'replace-wait', prompt `new text:`. `d` → drop
   (walked grows undefined), index+1. Any other line → re-prompt. When index >= total → phase
   'walk-summary', prompt `goals updated (w to write, q to abort)`. replace-wait: the line is
   trimmed first; blank (whitespace only) → re-ask (blank would fail min(1)); else the entry
   gets that text and source RESOLVE_CONFIRM_SOURCE, walked grows with it, index+1, phase
   'walk' (or 'walk-summary' when index reaches total). walk-summary: `w` → rebuild the lists
   from walked (goal decisions sit at positions 0 to goals.length-1, non-goals the rest;
   undefined entries are omitted) → writes = the $.goals write of the rebuilt goals + a
   $.nonGoals write only when the rebuilt nonGoals differ from input.goals.nonGoals by
   JSON.stringify → the lists are re-set, phase 'main', out = the main content again (it shows
   the edited goals), no result (the step completes on the accept); `w` with no goal left →
   the line `every goal was dropped: keep or replace at least one (q to drop the edits)`, stay
   (no result); `q` → phase 'main' (the walk is dropped: walked reset; goals/nonGoals and
   writes stay as they were), out = the main content; any other line → re-prompt.
