## Repo map — what goes where

```
CLAUDE.md            ← you are here: map + iron rules
README.md            ← human landing page (links into docs/)
install.sh           ← ROCm stack install (amdgpu-install + render/video groups)
docs/
  GUIDE.md           ← generic how-to for both tracks (the operator guide; was RUNBOOK.md)
  INDEX.md           ← register of every report, newest first — GENERATED by reindex.py
  reindex.py         ← rebuilds INDEX.md from each report's <!-- meta --> block (fails if missing);
                       scans docs/{analysis,research}/ AND campaigns/*/analysis.md
  research/          ← EXTERNAL synthesis: what the world knows, sourced   (dated)
  analysis/          ← OUR measurements: standalone/one-off reports         (dated)
  vllm/              ← vLLM knowledge base (versions / settings / known-issues / workflows / sources)
campaigns/           ← (PROJECT ROOT) self-contained campaigns = "runbooks" (starter-baseline,
                       deep-context, …); each holds spec.json + generated run.sh + README + its
                       co-located analysis.md write-up; scaffold new via /benchmark-new-campaign
bench/                 ← two tracks (see bench/README.md); how-to in docs/GUIDE.md
  gen_campaign.py    ← deterministic campaign scaffolder, kinds throughput | quality | agentic (spec.json → resumable run.sh + README;
                       continue-on-fail + pre-flight VRAM guard); also `vram-ctx` calculator
  gguf_kv.py         ← read KV-cache geometry from a .gguf → KiB/tok + paste-ready `vram` block
                       (authoritative source for the guard; beats online "will it fit" tools)
  model-bench/       ← tuning microscope: run.sh (manual grid) + sweep.py (ADAPTIVE optimum
                       search: grid expands until peak bracketed; KV f16-vs-q8_0 ≤5% rule)
  engine-bench/      ← cross-engine + serving combos: serve_llamacpp.sh (BACKEND/MTP/KV/NP launcher),
                       run.sh + campaign.sh (MTP×KV×depth×parallel matrix, resumable) — all driving
                       bench/lib/capture_engine.py; llama-benchy (dl/benchy-venv)
  engine-bench/vllm/ ← vLLM (Sly radiance) tools: serve_vllm.sh + profiles/ + capture_proxy.py +
                       fetch_model.sh (observe via bench/lib/monitor.py; claude/monitor.sh wrapper)
  workloads/         ← build_prompt.py + tasks/ + corpus/ (tracked TS+Python source, ~565K tok);
                       generated/ ignored
  lib/               ← gpu_env.sh (AMD/NVIDIA vendor abstraction) + vram_sampler.py +
                       capture_engine.py (THE prober: `probe` throughput/concurrency + `tasks` quality
                       capture) + report.py (run/campaign dir → theme-aware SVG charts + appendix.md,
                       embedded in the analysis; kinds: quality|throughput|sweep)
  runs/              ← dated campaign outputs YYYY-MM-DD-HHMM-<slug>/ (results.jsonl/llama-bench.json)
  legacy/            ← ⚠️ FROZEN original harness (harness/ + old *.sh + *_results.jsonl); hardcodes
                       old path /home/dev/work/dippe/amd, does NOT run here; superseded. Reference only.
build/               ← backward-compat symlink → llamacpp/builds/
llamacpp/            ← llama.cpp build pipeline: build_llamacpp.sh, setup_vulkan.sh (Vulkan SDK)
                       builds/ (gitignored): <ver>-src, <ver>-{vulkan,rocm}/bin (+BUILD_INFO), latest-*
                       symlinks = what llama-swap serves. vulkansdk/ (gitignored): SDK downloads + installs
                       Fetch → build → bench vs previous → promote: /llamacpp-build
.claude/skills/
  research/               ← reproducible, sourced, hallucination-resistant web research
  benchmark-results/      ← run a benchmark AND document it to a fixed spec (memory column mandatory)
  benchmark-new-campaign/ ← design + scaffold a new campaign (judgement) → gen_campaign.py (emit)
  llamacpp-build/         ← new llama.cpp: llamacpp/build_llamacpp.sh → compare_builds.py → promote latest-*
                       Vulkan SDK: llamacpp/setup_vulkan.sh (download, verify, update)
```

**Never read (gitignored binaries / generated):** `bench/llamacpp*/`, `build/`, `bench/dl/`,
`unsloth_compiled_cache/`, `bench/**/*.log`, `bench/runs/*/*.err`. They are 3 GB of build
artifacts — reading them wastes tokens and tells you nothing. Structure/results live in the files
above. (Charts are now committed SVGs under `<campaign>/charts/`, embedded in `appendix.md`.)
