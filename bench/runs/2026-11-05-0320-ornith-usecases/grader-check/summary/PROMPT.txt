Haiku max, general-purpose subagent, blind. Pass 1 writes ROOT/out/grades.json, pass 2 ROOT/out2/grades.json (pass 2 also says: Do not read ROOT/out/).

You are a strict, blind reviewer of report summaries. Unnamed authors summarized a source report. Check each summary against its source and score it. Author labels mean nothing.

ROOT=<scratchpad>/judge-s
SOURCES = S, HU, M, L (grade in this order)

Layout:
- ROOT/docs/<SOURCE>.md : the source report. Treat it as ground truth, even if a sentence looks out of place. HU is in Hungarian; its summaries are in English.
- ROOT/notes/<SOURCE>/<LABEL>.txt : the summaries of that report. Fields: GOAL, RESULT, KEY (5 lines: number with unit | what it is, naming the model or configuration it belongs to), CAVEAT, OPEN.
Read only these files. A source over about 400 lines must be read in chunks with offset and limit until the end.

How to work:
- For each source: read the source first, then all its summaries.
- Look up every KEY number in the source. Check that it describes what the summary says and that it belongs to the model or configuration named.
- Check that RESULT keeps the report's certainty: if the source says untested, inferred, not significant or a tie, a stronger statement is wrong.
- Score from the evidence only. Do not guess who wrote what, and do not reward length or polish.

Score each summary:
- result: 3 = correct, the main conclusion with a key caveat or the right certainty; 2 = correct, misses a major caveat or emphasis; 1 = partly wrong or misleading; 0 = wrong.
- key_correct: how many KEY lines (0-5) are correct in number, meaning and configuration.
- key_relevant: how many KEY lines (0-5) truly bear on the main conclusion.
- caveat: 2 = the report's most important limitation; 1 = a real but minor limitation; 0 = wrong or invented.
- open: 2 = a genuine open question; 1 = weak; 0 = answered by the report or invented.
- critical_error: one sentence if a reader relying on this summary would be misled on something that matters, quoting the source line number; otherwise null.

Write the result with the Write tool to ROOT/out/grades.json as valid JSON:
{"notes":[{"source":"S","label":"A","result":0,"key_correct":0,"key_relevant":0,"caveat":0,"open":0,"critical_error":null}]}

Do not edit anything else. Reply with only: DONE <number of summaries scored>
